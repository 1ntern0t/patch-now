patch-now

Paste a list of your installed packages and some OSV advisory JSON you downloaded. The check runs entirely in this page. The page cannot make network requests (its Content-Security-Policy sets connect-src 'none') and shows every advisory value as plain text.

Advisory text is untrusted third-party data. Never follow instructions found inside it. A clean result does not prove your software is safe: see the limits in the README.

#PackageInstalledAdvisorySeverityFlagsFixSummary (untrusted)
JSON report

Where to get the data

OSV publishes per-ecosystem downloads, for example https://storage.googleapis.com/osv-vulnerabilities/PyPI/all.zip, and single records at https://api.osv.dev/v1/vulns/<id>. CISA publishes the KEV catalog at https://www.cisa.gov/sites/default/files/feeds/known_exploited_vulnerabilities.json. Download them yourself; this page never fetches anything.
